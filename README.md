# collabcode

To install dependencies:

```bash
bun install
```

To run backend:

```bash
bun run --filter @collabcode/backend dev
```

To run frontend:

```bash
bun run --filter @collabcode/frontend dev
```

This project was created using `bun init` in bun v1.3.14. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
